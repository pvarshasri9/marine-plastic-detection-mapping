# 🌊 Marine Plastic Detection Frontend

This is the React + TypeScript + Vite frontend client for the **Marine Plastic Detection & Mapping System**.

---

## ⚡ How to Run

To run the complete application (Frontend + Backend concurrently), execute from the **project root**:

```bash
npm run dev
```

### URLs:

- **Frontend UI**: [http://localhost:5173](http://localhost:5173)
- **Backend API**: [http://localhost:8000](http://localhost:8000)

---

## 🛠 Tech Stack & Libraries

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Mapping**: Leaflet + React-Leaflet
- **Analytics Charts**: Recharts
- **API Client**: Axios (with JWT auth interceptor)
- **Upload**: React-Dropzone
